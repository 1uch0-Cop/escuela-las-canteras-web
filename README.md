# Escuela Las Canteras — sitio web institucional

Sitio web estático de la Escuela Las Canteras de Copiapó, publicado mediante GitHub Pages.

## Estructura principal

- `index.html`: portada y noticias destacadas.
- `escuela.html`: información institucional.
- `sello.html`: sello institucional.
- `contacto.html`: información de contacto.
- `noticia-*.html`: noticias institucionales.
- `styles.css`: estilos globales.
- `main.js`: navegación, carrusel, galería y normalización de enlaces.
- `assets/`: imágenes, logotipo y documentos PDF.
- `CNAME`: dominio personalizado de GitHub Pages.
- `robots.txt` y `sitemap.xml`: indexación y SEO técnico.
- `404.html`: página personalizada para recursos inexistentes.

## Publicación

La rama de publicación es `main` y el dominio configurado es:

`www.escuelalascanterascopiapo.cl`

## Mantenimiento

1. Crear una rama de trabajo desde `main`.
2. Realizar y revisar los cambios en esa rama.
3. Abrir un Pull Request hacia `main`.
4. Integrar solo después de verificar enlaces, imágenes y contenido.

No deben versionarse archivos locales de editor, credenciales, claves, archivos temporales ni información sensible.

## Contenido institucional

Antes de publicar fotografías, documentos o datos de estudiantes y miembros de la comunidad educativa, debe verificarse que su publicación esté autorizada conforme a las políticas institucionales aplicables.
