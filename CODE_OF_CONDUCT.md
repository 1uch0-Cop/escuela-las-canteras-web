# Código de conducta

Este proyecto promueve una colaboración respetuosa, educativa y profesional.

## Comportamiento esperado

Las personas participantes deben:

- comunicarse con respeto;
- realizar críticas técnicas constructivas;
- proteger la privacidad de estudiantes y funcionarios;
- evitar lenguaje discriminatorio, intimidatorio o agresivo;
- respetar los derechos de autor y la identidad institucional;
- utilizar el proyecto únicamente con fines legítimos.

## Comportamiento no aceptado

No se permitirá:

- acoso o discriminación;
- publicación de datos personales;
- exposición de menores de edad;
- difusión de credenciales o información interna;
- incorporación de material sin autorización;
- uso del proyecto para suplantación, fraude o actividades maliciosas.

## Aplicación

Las contribuciones que incumplan estas normas podrán ser rechazadas, modificadas o retiradas.
