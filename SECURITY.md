# Política de seguridad

Este repositorio contiene el sitio web institucional público de Escuela Las Canteras de Copiapó.

## Alcance

El sitio es estático y se publica mediante GitHub Pages. No debe contener credenciales, tokens, claves privadas, archivos `.env`, bases de datos, respaldos ni información personal que no esté destinada a publicación pública.

## Reporte de vulnerabilidades

Si detectas una vulnerabilidad o exposición de información sensible, evita publicarla en un issue público. Informa directamente al responsable técnico del sitio mediante el canal institucional correspondiente.

## Reglas de mantenimiento

- Trabajar mediante ramas y Pull Requests.
- No incorporar secretos ni credenciales al repositorio.
- Revisar enlaces externos antes de publicar.
- Evitar scripts, iframes y recursos de terceros salvo necesidad justificada.
- Mantener `target="_blank"` acompañado de `rel="noopener noreferrer"`.
- Revisar metadatos y contenido de documentos e imágenes antes de hacerlos públicos.
- Mantener copias de seguridad fuera del repositorio público.

## Dependencias externas

Toda dependencia externa debe minimizarse y revisarse periódicamente por motivos de seguridad, privacidad y disponibilidad.
