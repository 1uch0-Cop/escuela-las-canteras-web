# Política de seguridad

## Reporte responsable

No publique inicialmente como incidencia pública información que pueda:

- exponer datos personales de estudiantes o funcionarios;
- revelar credenciales o accesos internos;
- afectar la Intranet u otros servicios institucionales;
- permitir la modificación no autorizada del sitio;
- facilitar suplantación, phishing o abuso de identidad institucional.

Los reportes deben enviarse de manera privada a:

secretariaescuelalascanteras@gmail.com

Incluya, cuando sea posible:

- descripción del problema;
- URL o archivo afectado;
- pasos para reproducirlo;
- impacto estimado;
- capturas o evidencias sin datos personales innecesarios.

## Alcance

Este repositorio contiene un sitio web estático.

No incluye:

- backend;
- base de datos;
- autenticación;
- procesamiento propio de formularios;
- almacenamiento de credenciales;
- tratamiento automatizado de datos personales.

## Divulgación

Se solicita no divulgar públicamente una vulnerabilidad antes de que haya sido revisada y corregida.

## Privacidad

Los incidentes relacionados con fotografías, nombres, documentos o datos de la comunidad educativa serán tratados prioritariamente como problemas de privacidad.
